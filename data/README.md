# data/

Published processed results — every number in the manuscript is taken from
`tables/`. Raw public benchmark data is **not** shipped (see the root README);
these files are generated from pinned dataset revisions and API runs by the
scripts listed below.

## processed/ — item-level processed data

- `full_pilot_v1.jsonl` — item-level rows for the 530 development problems
  (model, setting, repetition, accuracy, reasoning tokens, latency, cost)
- `flash_router_dataset.csv` — item-level router feature set

## run_summaries/ — per-run provenance

One small JSON per API run (`run_id`, stage, planned/executed/completed/failed
requests, timestamps). The full per-run JSONL logs are regenerated by the
pipeline and written to `work/metrics/`; they are not shipped.

## Runtime vs published

When you re-run the pipeline, regenerated artifacts go to `work/` (gitignored).
`tables/`, `figures/`, `processed/` and `run_summaries/` here are the frozen
snapshots that correspond to the submitted manuscript.
